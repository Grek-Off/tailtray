# TailTray

TailTray is an unofficial native tray controller for the official Tailscale
daemon on Linux. It is being built first for Fedora/GNOME and KDE.

The project does **not** implement a VPN engine and does not replace
`tailscaled`. Networking, device identity, and node state remain in the
official Tailscale service.

> Work in progress. Installation and usage instructions will be added with the
> Fedora packaging.
